# Combined development status

The six supplied mechanisms are unchanged. Fitting uses the exact System B heteroscedastic Gaussian likelihood and the left-censored Q probability. A missing row supplies no observation; a below-LOQ row supplies an inequality event. Independent starting guesses are used, and only converged finite solutions are eligible for selection.

M2 and M4 remain indistinguishable on the historical 4:1 charge. Predictions use their saved 60-fit bootstrap distributions with fixed relative AIC weights. These are comparative scores, not probabilities that a mechanism is true. The reported intervals include measurement noise; they are not confidence intervals for the mean reaction curve.

The testing team's five-fold diagnostic is retained and regenerated from 100 saved training-only bootstrap fits per model per fold. All 1,000 supplied fits converged, none flagged a parameter bound. Each fold's mixture weights come from that fold's four training experiments.
